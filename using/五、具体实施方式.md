# 五、具体实施方式

为使本发明的目的、技术方案和有益效果更加清楚明白，下面结合 OpenVTER 项目的具体实现对本发明作进一步详细说明。应当说明，以下实施方式仅用于说明本发明，而不用于限定本发明的保护范围。

本实施方式以配置文件 config/demo_config/video_config/20220303_5_E_300_fusion_yolov5.json 所对应的无人机俯视交通视频处理流程为例进行说明。该配置采用双检测模型融合策略，检测模块包括 centernet_bbavectors.json 与 yolov5_extra.json，跟踪模块包括 sort_r_vehicle_group.json 与 sort_r_vru_group.json，输出帧率 out_fps=29.97，推理批大小 inference_batch_size=10，切块参数为 subsize_width=560、subsize_height=448、split_gap=160。

## 实施例一：方法流程

本实施例对应的整体处理流程由 DroneVideoProcess 类完成，处理结果保存在 det_bbox_result 结构中，其中包括 video_info、output_info、traj_info 和 raw_det 等字段；在一实施方式中，traj_info 中每个元素记录为 (frame_index, output_frame, o_bboxs_res) 或 (frame_index, output_frame, o_bboxs_res, frame_time)，用于后续导出结构化轨迹结果。

S1、数据获取与道路配置加载：首先读取无人机俯视视频流，并通过 RoadConfig.fromfile() 载入道路配置文件。当前工程中，道路配置文件由标注 JSON 构成，标注项至少包括稳像区域 fp、检测区域 road、车道区域 lane_i、像素尺度标记 length_*、坐标轴基准 x 和 y，以及可选的 drivingline*、laneline_* 和交叉口区域 int*。经解析后生成的道路配置字典至少包含 det_mask、stab_mask、length_per_pixel、base_points、x_axis_vector、y_axis_vector、lane 和 pixel2xy_matrix 等字段。其中，det_mask 用于约束目标检测区域，stab_mask 用于约束稳像特征提取区域，pixel2xy_matrix 用于将像素坐标映射到世界坐标。

S2、预处理与视频稳像：在当前项目中，若处理流程包含 stab，则优选预先由 VideoStabilization 模块生成稳像变换文件，并在推理阶段通过 load_transforms() 载入。稳像变换的计算过程为：在 stab_mask 掩膜内提取角点特征，特征提取参数示例为 maxCorners=200、qualityLevel=0.05、minDistance=7、blockSize=10、useHarrisDetector=True、k=0.04；随后采用 cv2.calcOpticalFlowPyrLK 计算相邻帧特征点位移，再采用 cv2.estimateAffinePartial2D 估计帧间部分仿射变换矩阵，并基于该矩阵对当前帧执行几何补偿。完成稳像后，对补偿帧施加 det_mask 检测掩膜，仅保留道路交通目标所在区域。之后调用 splitbase(gap=self.split_gap, subsize_height=subsize_height, subsize_width=subsize_width) 将整帧按重叠滑窗切分为若干图像块，以增强边缘目标保留能力并提高小目标召回率。

S3、多模型推理与统一表达：对每个图像块，分别调用旋转框车辆检测模型和多类交通参与者检测模型执行批量推理。在本实施例中，第一检测模型为 centernet_bbavectors，其示例参数包括 confidence=0.3、img_width=640、img_height=512、max_object_num=100，输出类别包括 car、truck、bus、freight_car、van；第二检测模型为 yolov5，其示例参数包括 confidence=0.2、nms_iou=0.45、img_width=640、img_height=640，原始检测类别通过 class_id_map=[5,6,7,0,0,0,8,9,0,10] 映射到统一类别空间。统一类别空间对应 global_category，依次为 car、truck、bus、freight_car、van、pedestrian、people、bicycle、tricycle、awning-tricycle 和 motor。不同检测模型输出经类别映射后，统一转换为旋转框表示 R=[cx,cy,w,h,θ,x1,y1,x2,y2,x3,y3,x4,y4,s,c]，其中 cx、cy 为目标中心坐标，w、h 为旋转框宽高，θ 为方向角，x1~x4、y1~y4 为四顶点坐标，s 为置信度，c 为统一类别标识。

S4、全局融合与旋转非极大值抑制：对于每个图像块得到的候选检测结果，先根据图像块在原图中的偏移量执行坐标回投，形成全图候选集 all_bbox。随后采用 nms_rotated(all_bbox[:, :5], all_bbox[:, score_col], nms_iou, all_bbox[:, cat_col]) 对候选结果执行按类别约束的旋转非极大值抑制，得到保留索引 keep_inds 和融合检测结果 nms_all_bbox。在一实施方式中，当融合结果数量超过上限 max_object_num 或默认上限 500 时，可再依据置信度进行 Top-K 裁剪。经该步骤得到的融合检测集合可记为 D，其每一行优选至少包含像素四顶点、置信度、类别标识等信息。

S5、分组跟踪与统一编号：将融合检测集合 D 按类别分配至不同跟踪器。本实施例中，机动车组使用 sort_r_vehicle_group.json，其 class_ids=[0,1,2,3,4]、id_offset=0；弱势交通参与者组使用 sort_r_vru_group.json，其 class_ids=[5,6,7,8,9,10]、id_offset=100000。两组跟踪器均采用 sort_r 模型，示例参数为 match_iou_threshold1=0.9、match_iou_threshold2=0.2、max_age=30、min_hits=3、iou_threshold=0.3。每个跟踪器分别执行状态预测、检测框与轨迹的关联匹配以及轨迹更新，最后通过 id_offset 机制将各组轨迹编号映射到全局唯一 ID 空间，从而避免跨组 ID 冲突。更新后的结果中，类别索引位于检测矩阵的第 10 列（索引 9），轨迹 ID 位于第 11 列（索引 10）。

S6、空间语义增强与车辆细分类稳定化：对完成跟踪后的旋转框结果，调用 _pixel_to_xy() 将像素四顶点坐标映射至世界坐标。具体做法为：取像素四顶点矩阵 P=[x_i,y_i,1]^T，通过 pixel2xy_matrix 计算对应世界坐标顶点，再将所得 8 个世界坐标值附加在检测矩阵后部。在当前工程实现中，若原始检测矩阵前 11 列依次为像素四顶点、置信度、类别和轨迹 ID，则映射后第 12 至第 19 列为世界坐标四顶点。随后调用 _get_lane_id()，以像素四顶点中心点 pixel_cts=mean(pts_px, axis=1) 作为车道归属判定中心，利用 isPointinPolygon() 对 lane 字典中的车道多边形执行点内判定，将 lane_id 附加在检测矩阵末列。然后调用 _assign_vehicle_cat_by_length_masked() 对机动车类别进行长度驱动的再分类，并调用 _stabilize_track_categories() 对同一轨迹的类别序列进行时序平滑。在本实施例中，类别平滑窗口 track_cat_window=7，最小投票样本数 track_cat_min_samples=3，长度平滑窗口 track_len_window=7，历史缓存清理阈值 track_history_ttl=200。

S7、轨迹物理约束后处理与结构化输出：在本实施例中，轨迹后处理由 track_gap_fill_export.py 脚本给出参考实现。该脚本先按 track_id 建立完整时间轴 f_min..f_max，对缺失帧执行补全；对观测帧记录 fill_type="observed"，对插值帧记录 fill_type="linear" 或 fill_type="predict_low_conf"。随后根据是否存在完整世界坐标，计算目标中心点序列、速度、加速度、航向角、切向/法向分量，并施加静止门控和物理阈值约束。处理完成后，导出的结构化记录优选至少包含 frame_index、output_frame、track_id、category、category_name、fill_type、gap_size、像素坐标、世界坐标、lane_id、speed、accel、heading、is_stationary、phys_violation 和 valid_phys 等字段。当设置 drop_unreliable_phys=True 时，对不满足可靠条件的物理量字段可置为 NaN，从而提高后续统计分析的可信度。

## 实施例二：关键计算与变量说明

1. 稳像仿射变换计算：在 VideoStabilization 模块中，若前一帧特征点集合记为 prev_pts，当前帧对应特征点集合记为 curr_pts，则通过 cv2.estimateAffinePartial2D(curr_pts, prev_pts) 估计部分仿射矩阵 M_aff。设 M_aff=[[m11,m12,dx],[m21,m22,dy]]，则平移量为 dx=M_aff[0,2]、dy=M_aff[1,2]，旋转角可表示为 da=atan2(m21,m11)。该变换既可用于离线生成稳像变换文件，也可用于在线对当前帧执行几何补偿。

2. 统一旋转框表达：多模型输出被统一为 R=[cx,cy,w,h,θ,x1,y1,x2,y2,x3,y3,x4,y4,s,c]。其中，前 5 个参数可直接用于 nms_rotated() 执行旋转框抑制，四顶点参数可用于后续世界坐标映射、长度估计和可视化绘制。当前工程中，轨迹 ID 在跟踪后附加至矩阵第 11 列，世界坐标四顶点经 _pixel_to_xy() 附加于后续列，lane_id 进一步附加为末列。

3. 像素到世界坐标映射：对任一点像素坐标 p=[x,y,1]^T，其对应世界坐标可表示为 q=[X,Y]^T = pixel2xy_matrix · p。在实现中，先将检测矩阵前 8 列重排为四个像素顶点，再为每个顶点补一列常数 1，形成齐次坐标矩阵，最后通过矩阵乘法得到 8 个世界坐标值并附加到原检测矩阵后部。

4. 车辆长度计算：当前项目中，车辆长度通过 _compute_bbox_lengths() 计算。设四顶点集合为 p_i(i=1..4)，则任意两点距离为 d_ij=||p_i-p_j||_2，车辆长度取 L=max(d_ij)。实现时优先采用世界坐标四顶点计算；若世界坐标不可用，则退回使用像素四顶点，并乘以 length_per_pixel 转换为物理长度。

5. 车辆子类映射：本实施例中，车辆子类映射函数为 _vehicle_cat_from_length()，阈值向量采用 vehicle_length_thresholds=[4.8,6.8,9.5,12.0]。当 L<4.8 时映射为 car；当 4.8≤L<6.8 时映射为 van；当 6.8≤L<9.5 时映射为 truck；当 9.5≤L<12.0 时映射为 bus；当 L≥12.0 时映射为 freight_car。在工程实现中，上述类别分别对应统一类别空间中的索引 0、4、1、2、3。

6. 轨迹级类别时序平滑：设某轨迹 τ 在最近 K=track_cat_window 帧内的类别历史为 C_τ={c_(t-K+1),...,c_t}，长度历史为 H_τ={L_(t-K+1),...,L_t}。若当前轨迹被判定为机动车轨迹且 H_τ 非空，则先取长度中值 L_med=median(H_τ)，再通过 _vehicle_cat_from_length(L_med) 更新当前类别；否则，当历史样本数不少于 track_cat_min_samples 时，对 C_τ 统计投票，若最大票数唯一，则采用众数类别作为平滑后类别。每隔 50 帧，还根据 track_history_ttl=200 清理长期未出现轨迹的历史缓存。

7. 轨迹缺帧补全：设同一轨迹上相邻两观测帧为 f0 和 f1，中间存在缺口 gap=f1-f0-1。对任一缺失帧 f，其插值比例为 ratio=(f-f0)/(f1-f0)。若左右两端均存在像素顶点，则像素插值结果为 P_f=P_f0+(P_f1-P_f0)·ratio；若左右两端均存在世界坐标，则世界坐标插值结果为 W_f=W_f0+(W_f1-W_f0)·ratio。当前示例导出脚本中，当 gap≤g2 时记录 fill_type="linear"，当 gap>g2 时记录 fill_type="predict_low_conf"；其中默认参数 g1=4、g2=12、g3=30 保留在导出接口中，便于后续扩展更细的缺口等级。

8. 中值平滑与 Savitzky-Golay 平滑：当前导出脚本支持 smooth_method="median" 与 smooth_method="savgol" 两种模式。中值平滑 _median_smooth_1d() 对长度为 smooth_window 的滑动窗口求中值；Savitzky-Golay 平滑先通过 _sanitize_sg_window() 修正窗口长度，再通过 _savgol_coeffs(window, poly, deriv, delta) 计算系数，对中心点序列进行 0 阶、1 阶和 2 阶滤波，分别得到平滑位置、速度和加速度。示例参数为 smooth_window=5、sg_window=9、sg_poly=2。

9. 速度、加速度与航向角：设平滑后的中心点序列为 (x_t,y_t)，采样时间间隔为 Δt=1/fps，则 x_vel=dx/dt、y_vel=dy/dt，速度模长为 speed=sqrt(x_vel^2+y_vel^2)；加速度分量为 x_acc=d(x_vel)/dt、y_acc=d(y_vel)/dt，加速度模长为 accel=sqrt(x_acc^2+y_acc^2)；航向角为 heading=degrees(atan2(y_vel,x_vel))。在 median 模式下，速度和加速度通过中心差分 _central_diff() 计算；在 savgol 模式下，上述量可直接由不同阶次的 Savitzky-Golay 滤波结果获得。

10. 切向/法向分解：当采用世界坐标时，给定参考中心 (center_x,center_y)，径向单位向量通过 _unit_radial() 计算，记为 (r_x,r_y)，切向单位向量为 (t_x,t_y)=(-r_y,r_x)。则切向速度 v_t=x_vel·t_x+y_vel·t_y，法向速度 v_n=x_vel·r_x+y_vel·r_y，切向加速度 a_t=x_acc·t_x+y_acc·t_y，法向加速度 a_n=x_acc·r_x+y_acc·r_y。当前脚本默认 center_x=0.0、center_y=0.0、center_eps=1e-3。

11. 静止门控：当前实现采用“两级静止门控”策略。第一层门控统计连续低速区间，若 speed<v_stop 的连续帧长度不少于 k_stop，则将对应区段标记为静止；第二层门控调用 _stationary_dominance_mask()，在长度为 stat_window 的滑动窗口内统计低速占比 ρ，若 ρ≥stat_ratio，则将该帧标记为静止。被标记为静止的帧，其 x_vel、y_vel、speed、x_acc、y_acc 和 accel 被钳制为 0；在世界坐标模式下，heading 被置为 NaN。

12. 物理异常约束与可靠性标记：设车辆轨迹的最大允许速度为 vmax_vehicle=15.0m/s、最大允许加速度为 amax_vehicle=3.0m/s^2，弱势交通参与者的最大允许速度为 vmax_vru=9.0m/s、最大允许加速度为 amax_vru=3.0m/s^2，则物理异常标志定义为 phys_violation=(speed>vmax) | (accel>amax)。此外，当前实现还通过 _valid_phys_mask() 对观测连续性进行判定，仅对满足连续观测窗口条件的帧保留可靠物理量；当 drop_unreliable_phys=True 时，不可靠帧的 speed、accel、v_tangent、v_normal、a_tangent 和 a_normal 等字段可置为 NaN。

## 实施例三：关键参数与配置示例

1. 视频与切块参数：本实施例中，视频输出帧率 out_fps=29.97，推理批大小 inference_batch_size=10，图像块宽度 subsize_width=560，图像块高度 subsize_height=448，重叠步长 split_gap=160。通过上述参数组合，可兼顾无人机俯视场景下的大视场覆盖和小目标检测召回。

2. 稳像参数：在一实施方式中，特征点提取参数可设置为 maxCorners=200、qualityLevel=0.05、minDistance=7、blockSize=10、useHarrisDetector=True、k=0.04，稳像关键帧间隔 stabilize_gap=30。推理阶段可结合 stabilize_file 读取预先生成的稳像变换。

3. 检测模型参数：车辆旋转框检测模型 centernet_bbavectors 的示例配置包括 confidence=0.3、img_width=640、img_height=512、max_object_num=100；多类目标检测模型 yolov5_extra 的示例配置包括 confidence=0.2、nms_iou=0.45、img_width=640、img_height=640、classes=[0,1,2,6,7,9] 以及 class_id_map=[5,6,7,0,0,0,8,9,0,10]。

4. 统一类别空间：本实施例采用的统一类别序列为 ["car","truck","bus","freight_car","van","pedestrian","people","bicycle","tricycle","awning-tricycle","motor"]，可视化标签示例为 bbox_label=["id","cat","score","lane"]。其中，前五类为机动车类别，后六类为弱势交通参与者类别。

5. 跟踪器参数：机动车跟踪器参数为 class_ids=[0,1,2,3,4]、id_offset=0；弱势交通参与者跟踪器参数为 class_ids=[5,6,7,8,9,10]、id_offset=100000。两组跟踪器共享 match_iou_threshold1=0.9、match_iou_threshold2=0.2、max_age=30、min_hits=3 和 iou_threshold=0.3 等参数。

6. 长度重分类与类别平滑参数：车辆长度阈值采用 vehicle_length_thresholds=[4.8,6.8,9.5,12.0]；类别投票窗口 track_cat_window=7；最小类别投票样本 track_cat_min_samples=3；长度平滑窗口 track_len_window=7；历史缓存失效阈值 track_history_ttl=200。

7. 缺帧补全与平滑参数：当前导出脚本中，缺口分级接口参数包括 g1=4、g2=12、g3=30；位置平滑窗口 smooth_window=5；平滑方法优选 smooth_method="savgol"；Savitzky-Golay 参数为 sg_window=9、sg_poly=2。在当前示例实现中，g2 是线性补全与低置信预测的主要分界。

8. 静止门控与物理约束参数：静止速度阈值 v_stop=0.25m/s，连续低速最小帧数 k_stop=15，静止占优窗口 stat_window=30，占优比例阈值 stat_ratio=0.8；机动车物理阈值为 vmax_vehicle=15.0m/s、amax_vehicle=3.0m/s^2，弱势交通参与者物理阈值为 vmax_vru=9.0m/s、amax_vru=3.0m/s^2；切向/法向分解参考中心默认为 center_x=0.0、center_y=0.0、center_eps=1e-3。

9. 输出与可靠性控制参数：当 drop_unreliable_phys=True 时，对不满足连续观测窗口条件的物理字段实施空值处理；输出结果可以进一步导出为 Excel 或其他结构化文件格式，以支持轨迹分析、交通状态评估和后续智能交通应用。

上述参数和配置仅为本发明在当前工程中的一组优选实施例，用于说明本发明可以如何实施，并不构成对本发明保护范围的限制。在不脱离本发明核心思想的前提下，本领域技术人员可对参数取值、模型组合、输出格式和阈值策略作出等效替换或调整。
