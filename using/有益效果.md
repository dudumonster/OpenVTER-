# 有益效果

## （三）有益效果
与现有技术相比，本发明至少具有以下有益效果：

1. 通过稳像区域掩膜与检测区域掩膜的双掩膜预处理、重叠滑窗分块、多模型协同检测、类别映射表对齐以及全局旋转非极大值抑制，本发明能够在无人机俯视交通场景下显著提升小目标、边缘目标、密集目标及尺度变化显著目标的检测召回率与定位稳定性，同时降低不同检测模型之间语义空间不一致所引起的误检、漏检及重复检测。

2. 通过将机动车与弱势交通参与者分别输入不同的分组多目标跟踪器，并结合轨迹编号偏移量机制进行编号隔离，本发明能够有效抑制跨类关联冲突、轨迹漂移及 ID 切换问题，从而提高长时序多类交通参与者轨迹的连续性、稳定性与一致性。

3. 通过像素-世界坐标仿射映射、车道多边形归属判定、基于目标物理长度的车辆子类重分类以及轨迹级类别时序平滑，本发明能够提高车辆细分类结果的稳定性与可信度，并增强轨迹结果的空间语义完整性，为后续交通行为分析、车道级统计和数据挖掘提供更高质量的数据基础。

4. 通过完整时间轴重建、缺帧分级补全、轨迹中心点平滑、静止门控以及运动学物理约束校验，本发明构建了面向轨迹结果的质量控制闭环，能够显著抑制速度尖峰、加速度异常和静止目标伪运动现象，进而提升轨迹结果的连续性、可解释性与运动学可置信度。

5. 通过输出包含轨迹编号、目标类别、世界坐标、车道标识及运动学字段的结构化轨迹结果，并支持可视化结果导出与批量配置生成，本发明能够降低大规模部署中的人工配置成本与工程适配工作量，提升跨城市、跨路口、跨场景复制部署的效率和项目落地能力。
