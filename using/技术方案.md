# 技术方案

## （二）技术方案
为解决上述技术问题，本发明提供一种基于多模型融合与轨迹物理约束的无人机航拍多类交通参与者轨迹提取方法。该方法以无人机俯视交通视频为输入，以道路配置数据为先验约束，通过双掩膜预处理、多模型协同检测、分组多目标跟踪、空间语义增强以及轨迹物理一致性后处理，生成结构化轨迹结果。所述方法至少包括如下步骤：

S1、数据获取与道路配置加载：获取无人机俯视交通视频流，并加载与所述视频对应的道路配置数据，所述道路配置数据至少包括稳像区域掩膜、检测区域掩膜、车道多边形、像素尺度标定信息以及像素-世界坐标仿射映射参数，以为后续视频稳像、目标筛选和空间语义增强提供先验约束。

S2、双掩膜预处理与视频稳像：在所述稳像区域掩膜内提取角点特征，采用金字塔 Lucas-Kanade 光流法计算相邻帧特征点位移，并基于部分仿射模型估计帧间几何变换参数，对当前视频帧进行几何补偿；在完成稳像后，对补偿帧施加检测区域兴趣区域掩膜约束，以滤除与交通参与者无关的背景区域并降低无效计算量。

S3、重叠滑窗分块与多模型并行推理：将经预处理的视频帧按照预设子图尺寸和重叠步长执行滑窗分块，构建重叠子图集合，以增强边缘目标保留能力并提高小目标及尺度变化显著目标的检测召回率；分别将所述子图输入旋转框车辆检测模型和多类交通参与者检测模型进行并行推理，获得多源候选检测结果。

S4、统一旋转框表达与全局融合：将不同检测模型输出通过类别映射表对齐至统一类别空间，并统一转换为有向包围框表示，所述统一检测结果可表示为 R=[cx, cy, w, h, θ, x1, y1, x2, y2, x3, y3, x4, y4, s, c]，其中 cx、cy 表示目标中心坐标，w、h 表示目标宽高，θ 表示目标方向角，x1 至 x4 和 y1 至 y4 表示四顶点坐标，s 表示置信度，c 表示统一类别标识；随后将各子图检测结果回投至全图坐标系，并采用按类别约束的全局旋转非极大值抑制对重复候选框进行融合，得到全帧融合检测结果。

S5、分组多目标跟踪与统一编号：依据所述统一类别空间将融合检测结果划分为机动车目标集合与弱势交通参与者目标集合，并分别输入对应的跟踪器执行状态预测、数据关联与轨迹更新；各跟踪器采用轨迹编号偏移量机制进行编号隔离，以避免跨组 ID 冲突，并输出全局唯一的多类目标连续轨迹。

S6、空间语义增强与车辆细分类稳定化：对包含轨迹标识的有向包围框四顶点像素坐标执行像素-世界坐标仿射映射，其映射关系可表示为 [X, Y]^T = M·[x, y, 1]^T，其中 M 为由道路配置标定得到的仿射变换矩阵；基于映射后的世界坐标执行车道多边形归属判定，并依据目标物理长度对机动车轨迹进行车辆子类重分类；同时对同一轨迹的类别序列实施滑动窗口投票的轨迹级类别时序平滑，以抑制瞬时误分类导致的类别抖动。

S7、轨迹补全与物理一致性约束输出：按照轨迹标识构建完整时间轴，对缺失帧区段依据缺口长度实施分级补全，其中小缺口采用线性插值，中等缺口采用约束插值，大缺口采用低置信预测或分段处理；对补全后的轨迹中心点序列执行平滑处理并计算速度、加速度、航向角等运动学量，进一步通过静止门控和运动学物理约束对异常速度和异常加速度进行抑制或标记，最终输出包含帧号、轨迹编号、类别、世界坐标、车道标识及运动学字段的结构化轨迹结果，并支持可视化结果导出及批量配置生成。

通过上述技术方案，本发明将多模型检测表达统一、分组多目标跟踪、空间语义增强与物理一致性约束形成闭环处理链路，能够在无人机俯视交通场景下兼顾多类目标检测稳定性、轨迹连续性与工程部署效率。
