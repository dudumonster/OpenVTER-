# 中国发明专利申请初稿（基于OpenVTER项目）

## 【发明名称】（3-5个备选）
1. 一种基于多模型融合与轨迹物理约束的无人机航拍多类交通参与者轨迹提取方法、系统、设备及存储介质
2. 一种面向低空俯视交通视频的多检测器协同跟踪与物理一致性轨迹生成方法
3. 一种融合旋转框检测与分组跟踪的交通参与者轨迹提取方法及系统
4. 一种无人机交通视频多类目标检测跟踪及轨迹补全方法、设备与存储介质
5. 一种交通参与者多模型融合检测与物理约束轨迹建模方法及装置

## 【摘要】（(57)摘要风格）
本发明公开了一种基于多模型融合与轨迹物理约束的无人机航拍多类交通参与者轨迹提取方法、系统、设备及存储介质。该方法包括：获取无人机俯视视频与道路配置数据，对视频进行稳像、检测掩膜裁剪及分块处理；对分块图像分别执行旋转框检测模型与多类目标检测模型推理，并通过类别映射将检测结果统一为旋转框表达；在全局坐标下执行旋转非极大值抑制得到融合检测结果；按照类别分组将检测结果输入多个跟踪器并进行统一编号管理，输出连续轨迹；将像素坐标映射为世界坐标，执行基于目标物理长度的车辆细分类、轨迹级类别时序平滑及车道归属判定；进一步进行缺帧分级补全、运动学平滑、静止门控与物理一致性约束，输出结构化轨迹结果与可视化结果。该发明可有效降低遮挡、漏检与类别抖动导致的轨迹不稳定问题，提升多类交通参与者轨迹提取的连续性、可解释性与工程部署效率。

## 【说明书】
## 一、技术领域
本发明涉及计算机视觉、智能交通与低空无人机感知技术领域，具体涉及一种基于多模型融合与轨迹物理约束的无人机航拍多类交通参与者轨迹提取方法、系统、设备及存储介质。

## 二、背景技术
现有无人机交通视频轨迹提取方案通常采用“单检测器+单跟踪器”的流水线结构，在复杂路口、遮挡频发和尺度变化明显场景中易出现误检、漏检及跟踪漂移。
现有方法对检测类别的一致性处理不足：不同模型输出类别空间不一致，尤其在车辆与弱势交通参与者混合场景下，常出现类别抖动、跨类跟踪以及统计口径不统一的问题，影响轨迹数据的后续分析与应用。
现有方法普遍缺乏轨迹物理约束闭环。轨迹缺帧后直接差分求速度会造成速度尖峰和加速度异常，静止目标出现非零速度，导致轨迹结果难以满足交通行为分析、风险评估与高质量数据集生产需求。
此外，现有方案在工程部署阶段依赖人工逐视频配置，配置文件、背景图、道路标注初始化和模型路径维护工作量大，难以支持大规模场景快速复制。

## 三、发明内容
（一）技术问题
本发明旨在解决以下技术问题：
1. 如何在无人机俯视交通场景下兼顾机动车与弱势交通参与者的多类稳定检测与连续跟踪；
2. 如何在多模型协同条件下统一检测表达与类别语义，降低类别抖动和跨组ID冲突；
3. 如何在轨迹缺帧和抖动条件下保证速度、加速度等运动学指标的物理一致性与可解释性；
4. 如何降低大规模部署时的配置成本并提高项目落地效率。

（二）技术方案
为解决上述问题，本发明提供一种基于多模型融合与轨迹物理约束的轨迹提取技术方案，其核心链路为：
A. 基于稳像掩膜与检测掩膜的双掩膜预处理，结合重叠滑窗分块提高边缘与小目标检测稳定性；
B. 基于多检测模型协同推理与类别映射，构建统一旋转框检测表达，并在全图层面执行旋转非极大值抑制融合；
C. 基于类别分组的多跟踪器并行关联与统一ID管理，实现机动车与弱势交通参与者并行跟踪；
D. 基于世界坐标映射、目标物理长度重分类与轨迹级类别平滑，提升车辆细分类稳定性；
E. 基于缺帧分级补全、静止门控和物理约束校验，提升轨迹连续性与运动学可置信度；
F. 输出结构化轨迹文件并支持批量配置自动生成，满足规模化部署。

（三）有益效果
与现有技术相比，本发明至少具有以下有益效果：
1. 多模型融合与统一类别映射可在不牺牲多类覆盖能力的前提下维持旋转框检测精度，显著降低跨模型语义不一致导致的误差传播。
2. 类别分组多跟踪器与ID偏移机制可降低跨类关联冲突，提升长时序轨迹连续性和ID稳定性。
3. 物理长度重分类与轨迹级平滑可抑制车辆类别抖动，实现更稳健的车辆子类识别输出。
4. 缺帧分级补全、静止门控与物理约束形成闭环，显著改善速度和加速度尖峰，提升轨迹数据的可解释性与可用性。
5. 自动化配置生成与背景图导出可降低人工部署成本，提升跨城市、跨路口复制能力。

## 五、具体实施方式
以下结合优选实施例对本发明进行详细说明。应当理解，以下实施例仅用于说明本发明，而非用于限定本发明保护范围。

实施例一：方法流程
S1 数据获取：读取无人机视频和道路配置文件，所述道路配置文件至少包含：稳像掩膜fp区域、检测掩膜road区域、车道多边形lane_i、像素到世界坐标变换矩阵。
S2 预处理：在稳像掩膜内提取特征点，计算仿射变换矩阵对当前帧进行稳像；随后应用检测掩膜；将帧按设定窗口尺寸和重叠间隔切块。
S3 多模型推理与统一表达：对每个图像块执行旋转框检测模型与多类检测模型推理，将输出统一转换为旋转框表示R=[cx,cy,w,h,θ,x1,y1,x2,y2,x3,y3,x4,y4,score,cat]，并通过类别映射表将不同模型类别对齐到统一类别空间。
S4 融合抑制：将各块检测结果回投至全图坐标，执行按类别旋转NMS，得到融合检测集合D。
S5 分组跟踪：依据类别集合将D分配至机动车跟踪器和弱势交通参与者跟踪器，进行并行数据关联与状态更新，通过id_offset合并输出全局轨迹ID。
S6 空间语义增强：将目标四点像素坐标映射至世界坐标，进行车道归属判定；计算目标长度并按阈值区间进行车辆子类重分类；对同轨迹类别序列进行滑窗投票平滑。
S7 轨迹物理约束后处理：建立完整时间轴，按缺口长度分级执行插值/预测；对中心点序列进行平滑并计算速度、加速度、航向角；执行静止门控和物理阈值约束，输出结构化轨迹。

实施例二：关键计算
1. 车辆长度估计：设目标四点坐标为p_i(i=1..4)，目标长度L定义为四点两两距离最大值：L=max(||p_i-p_j||)。优选在世界坐标下计算L。
2. 车辆子类映射：设阈值向量T=[T1,T2,T3,T4]（示例：[4.8,6.8,9.5,12.0]米），当L<T1映射为car，T1≤L<T2映射为van，T2≤L<T3映射为truck，T3≤L<T4映射为bus，L≥T4映射为freight_car。
3. 速度与加速度：设中心点序列为(x_t,y_t)，时间间隔为Δt，则v_x(t)=d x_t/dt，v_y(t)=d y_t/dt，speed(t)=sqrt(v_x^2+v_y^2)；a_x(t)=d v_x/dt，a_y(t)=d v_y/dt，accel(t)=sqrt(a_x^2+a_y^2)。
4. 切向/法向分解：给定参考中心c=(c_x,c_y)，径向单位向量r=(r_x,r_y)，切向单位向量t=(-r_y,r_x)，则v_t=v_x*t_x+v_y*t_y，v_n=v_x*r_x+v_y*r_y；a_t=a_x*t_x+a_y*t_y，a_n=a_x*r_x+a_y*r_y。
5. 静止门控：在长度为W的时间窗内统计speed<v_stop的占比ρ，若ρ≥η则判定为静止状态并将对应时段速度、加速度钳制为0。

实施例三：关键参数表（示例）
1. 分块参数：subsize_width=560，subsize_height=448，split_gap=160；
2. 跟踪分组：机动车class_ids={0,1,2,3,4}，弱势交通参与者class_ids={5,6,7,8,9,10}；
3. 类别平滑：track_cat_window=7，track_cat_min_samples=3；
4. 缺口分级：G1=4帧，G2=12帧，G3=30帧；
5. 静止门控：v_stop=0.25m/s，k_stop=15帧，stat_window=30帧，stat_ratio=0.8。
注：上述参数为示例，不构成本发明保护范围限制。

实施例四：系统实现
系统可部署于具备GPU或CPU的边缘计算设备，软件架构包括视频处理主流程、检测模块、跟踪模块、坐标与语义增强模块、轨迹后处理模块及导出模块。系统输出包括：检测跟踪可视化视频、结构化轨迹文件（包含frame_index、track_id、类别、世界坐标、车道ID、运动学字段等），以及用于批量部署的配置清单。

实施例五：可选实现
在不偏离本发明核心思想情况下，检测模型可替换为任意旋转框检测器或水平框检测器；跟踪器可替换为基于卡尔曼滤波+匈牙利匹配、外观重识别或图优化关联方法；平滑器可替换为中值滤波、低通滤波、样条平滑或RTS平滑；物理约束可根据场景采用动态阈值策略。
